# 交付验收清单

## 运行

- [ ] `.env` 已从模板复制并替换生产密钥。
- [ ] PostgreSQL、Redis、MinIO、Embedding 健康。
- [ ] API `GET /health/live` 返回 `{"status":"ok"}`。
- [ ] API `GET /health/ready` 返回 `{"status":"ready"}`。
- [ ] 前端 `http://127.0.0.1:5173/` 可打开。

## 数据和存储

- [ ] `alembic upgrade head` 成功。
- [ ] 演示环境可重复执行种子脚本。
- [ ] 附件对象键不包含本地绝对路径。
- [ ] 本地存储拒绝 `../` 和绝对路径对象键。
- [ ] MinIO 预签名地址有效期不超过 300 秒。

## 业务链路

- [ ] 申请人能创建、编辑、提交费用报销单。
- [ ] 提交生成不可变版本并绑定附件。
- [ ] 分析任务由 Worker 异步执行，SSE 可恢复。
- [ ] 风险发现包含规则版本和证据；证据不足进入人工复核。
- [ ] 审批按部门审批 → 财务复核固定顺序推进。
- [ ] AI/Agent 不能直接改变审批状态。
- [ ] 报告绑定 `document_version_id` 并可查询/导出。
- [ ] 审批、复核、模型调用和敏感下载可在审计日志追溯。
