# 财务单据智能风险审核系统：本地使用说明

本文用于本地开发和演示。示例数据均为脱敏数据，不要把本文命令指向生产数据库。

## 1. 环境准备

- Python 3.11+
- `uv`
- PostgreSQL 16
- Docker Desktop（用于启动 PostgreSQL、Redis、MinIO 和 Milvus）

安装 Python 依赖：

```powershell
$env:UV_CACHE_DIR = (Join-Path (Get-Location) '.uv-cache')
uv sync
```

首次使用时，如果没有 `.env`，先复制模板：

```powershell
Copy-Item .env.example .env
```

## 2. 启动基础服务

启动 PostgreSQL、Redis、MinIO 和 Milvus standalone：

```powershell
docker compose up -d postgres redis minio milvus-etcd milvus-minio milvus
docker compose ps
```

停止基础服务但保留数据卷：

```powershell
docker compose stop
```

删除容器但保留数据卷：

```powershell
docker compose down
```

`docker compose down -v` 会删除 PostgreSQL、Redis、MinIO 和 Milvus 数据卷，仅在确认不需要数据时使用。

## 3. 初始化数据库和演示数据

如果从宿主机连接映射到 `localhost:5432` 的 PostgreSQL，请把连接串替换为本机实际账号和密码：

```powershell
$env:DATABASE_URL = "postgresql+asyncpg://<用户>:<密码>@localhost:5432/<数据库>"
uv run alembic upgrade head
uv run alembic current
uv run python seed_demo_data.py
```

`seed_demo_data.py` 可重复执行，不会重复创建同一批演示数据。当前演示数据包括：

- 3 个演示账号：`demo_applicant`、`demo_approver`、`demo_finance`
- 1 张费用报销单：`DEMO-20260818-001`，金额 `138.00 CNY`
- 2 个顺序审批节点、1 个待处理审批任务
- 1 个已完成分析任务、1 条低风险结论和 1 份报告
- 1 个审核会话、市场价格参考、供应商和审计记录

演示账号密码统一为 `Demo123!`，仅用于本地演示，部署前必须删除或替换。

## 4. 启动 API 和 Worker

宿主机运行 API 时，需要把后端切换到 PostgreSQL，并使用宿主机地址：

```powershell
$env:DOCUMENT_BACKEND = "postgres"
$env:AUTH_BACKEND = "postgres"
$env:DATABASE_URL = "postgresql+asyncpg://<用户>:<密码>@localhost:5432/<数据库>"
$env:REDIS_URL = "redis://localhost:6379/0"
$env:CELERY_BROKER_URL = "redis://localhost:6379/0"
$env:CELERY_RESULT_BACKEND = "redis://localhost:6379/0"

# 终端 1：API
uv run uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

# 终端 2：Celery Worker（Windows 本地开发使用 solo 池）
uv run celery -A app.tasks.celery_app worker --loglevel=INFO --pool=solo
```

检查 API：

```powershell
Invoke-RestMethod http://localhost:8000/health/live
Invoke-RestMethod http://localhost:8000/health/ready
```

停止宿主机 API 或 Worker：在对应终端按 `Ctrl+C`。

## 5. 登录和查看演示数据

登录接口：

```powershell
$body = @{ username = "demo_applicant"; password = "Demo123!" } | ConvertTo-Json
$login = Invoke-RestMethod `
  -Method Post `
  -Uri http://localhost:8000/api/v1/auth/login `
  -ContentType "application/json" `
  -Body $body

$headers = @{ Authorization = "Bearer $($login.access_token)" }
Invoke-RestMethod http://localhost:8000/api/v1/auth/me -Headers $headers
Invoke-RestMethod http://localhost:8000/api/v1/documents -Headers $headers
```

Swagger 文档地址：<http://localhost:8000/docs>。

## 6. 常用关闭和清理命令

```powershell
# 查看服务状态
docker compose ps

# 查看 PostgreSQL 日志
docker compose logs -f postgres

# 停止服务（保留数据）
docker compose stop

# 停止并删除容器（保留数据卷）
docker compose down

# 停止并删除容器及数据卷：会清空本地演示数据
docker compose down -v
```

如果只想清理演示数据而保留数据库结构，可直接删除 `seed_demo_data.py` 使用的演示主键对应记录，或重新创建本地数据库后执行迁移；不要在生产数据库执行清理命令。
