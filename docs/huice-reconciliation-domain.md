# 慧策·慧经营对账异常智能审核领域适配

本分支将通用财务风险审核系统收敛为面向多平台电商对账的异常审核场景。

## 业务对象

一次审核对象由以下数据组成，并全部绑定 `document_version_id`：

- ERP 订单：订单号、应收金额、支付金额、退款金额、订单状态。
- 平台结算：平台结算单号、结算金额、手续费、调整金额、结算周期。
- 退款记录：退款单号、退款金额、退款状态、原订单号。
- 金额调整：补扣款、平台赔付、营销补贴、其他调账。
- 实际回款：回款单号、到账金额、到账时间、收款主体。
- 账单附件：PDF/图片/Excel，解析结果需保留页码/位置、原文和置信度。

## 审核原则

1. 确定性规则负责形成风险事实，LLM 不覆盖规则结论。
2. 证据不足、OCR 低置信度或关键字段缺失时进入人工复核。
3. RAG 仅检索平台结算规则和内部财务制度，为风险事实补充依据。
4. LLM 基于风险事实 + 制度依据生成解释和处理建议，不直接改变审批状态。
5. 所有风险结果、人工复核、审批和报告都绑定不可变审核版本，保证历史可追溯。

## 核心规则

- 订单与平台结算金额差异
- 退款异常：退款金额大于订单实付、退款状态不一致、重复退款
- 重复结算：同一订单/结算流水出现重复结算
- 回款缺失：已结算但在允许账期内未找到实际回款
- 调账异常：调整金额超过阈值或缺少调整原因/依据
- 主体不一致：平台结算主体、店铺主体、实际收款主体不一致
- 关键字段完整性：订单号、结算单号、金额、主体等解析字段缺失或置信度不足

## 分层执行

```
账单/订单/退款/回款
        ↓
附件解析 + 结构化数据装配
        ↓
确定性规则引擎
        ↓
风险事实（证据绑定）
        ↓
RAG 检索平台规则/财务制度
        ↓
LLM 解释 + 处理建议
        ↓
人工复核 / 审批 / 报告
```

## 与原系统的映射

- `FinancialDocument/DocumentVersion`：对账审核对象及不可变版本。
- `document_attachments/attachment_parse_results`：账单与凭证解析。
- `RiskFinding`：金额差异、退款、重复结算、回款等风险事实。
- `RagService`：平台规则和财务制度检索。
- `manual_reviews`：低置信度或证据不足时人工复核。
- `approval_*`：财务审批流程。
- `ReviewReport`：最终可追溯审核报告。
